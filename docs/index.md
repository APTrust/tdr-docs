# APTrust Trusted Digital Repository Documentation

[ISO 16363](https://www.iso.org/standard/56510.html) — *Audit and certification of
trustworthy digital repositories* — is the international standard for assessing whether
a digital repository can be trusted to preserve content over the long term. It extends
the [OAIS Reference Model](https://public.ccsds.org/pubs/650x0m2.pdf) (ISO 14721) into a
set of criteria a repository can be measured against.

These pages are APTrust's self-assessment against that standard. Each criterion has its
own page giving the requirement, the supporting text and discussion from the standard,
and the evidence APTrust provides that it meets the requirement.

## How this documentation is organized

The standard is organized into three areas of criteria, preceded by APTrust's OAIS
conformance documents.

- **[Trusted Digital Repository](trusted-digital-repository.md)** — an overview of
  APTrust's documentation, policies, glossaries, and the ISO 16363 criteria.
- **[OAIS Documents](oais/index.md)** — how APTrust maps onto the OAIS reference model:
  its designated community, its mandatory responsibilities, and its definitions of
  [SIP](oais/02.04-definition-of-sip.md), [AIP](oais/02.02-definition-of-aip.md) and
  [DIP](oais/02.03-definition-of-dip.md).
- **[TDR 3.0 Organizational Infrastructure](tdr-3/index.md)** — governance, staffing,
  policy framework, financial sustainability, and contracts and licenses.
- **[TDR 4.0 Digital Object Management](tdr-4/index.md)** — ingest, AIP creation and
  preservation, preservation planning, information management, and access.
- **[TDR 5.0 Infrastructure and Security](tdr-5/index.md)** — technical infrastructure
  risk management and security risk management.

Use the navigation sidebar to move through the criteria in the order the standard
defines them, or the search box to find a specific criterion by number or topic.
