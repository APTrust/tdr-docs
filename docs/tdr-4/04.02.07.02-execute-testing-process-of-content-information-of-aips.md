# 4.2.7.2 Execute testing process of Content Information of AIPs

## Requirement Text

The repository shall execute the testing process for each class of Content Information of the AIPs.

## Evidence Provided

APTrust executes the documented testing process through restoration spot tests. This service is optional, and depositors must [opt in for restoration spot tests through Registry](https://docs.aptrust.org/user-guide/registry/spot_tests/).

The restoration spot test process:

- Selects one intellectual object from each depositor institution.
- Excludes objects restored within the previous 180 days.
- Currently limits selection to objects 50 GB or smaller to avoid excessive burden on depositors.
- Places the object into the restoration work queue using the same workflow as a depositor-initiated restore.
- Depositors are notified when the restored object is available to retrieve.

Depositors are expected to confirm:

- That the restored bag is complete.
- That it contains the expected content.
- That they can make sense of the restored materials.

This process is executed across all objects deposited by participating institutions.
