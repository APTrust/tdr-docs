# 4.2.4.1.3 Describe any processes for changes to identifiers

## Requirement Text

Documentation shall describe any processes used for changes to such identifiers.

## Evidence Provided

APTrust does not allow changes to semantic or internal identifiers, so there is no process for changing these identifiers. UUIDs assigned to objects and files for internal tracking (e.g., PREMIS events and files) are also immutable.
