# 4.2.1.1 Identify which definition applies to which AIP

The repository shall be able to identify which definition applies to which AIP.

## Supporting Text

This is necessary to ensure that the appropriate definition is used when parsing/interpreting an AIP.

## Examples for Meeting the Requirement

Documentation clearly linking each AIP, or class of AIPs, to its definition.

## Discussion

The repository may use any method for associating the definitions and the AIPs that provides for the continued and continuous linkage of the two entities.

## Evidence Provided

See the written definition of an APTrust AIP in our documentation for [Definition of an AIP](../oais/02.02-definition-of-aip.md), which describes all AIPs in APTrust’s control, and section [4.2.1 Associated definition for each AIP or class of AIPs](04.02.01-associated-definition-for-each-aip-or-class-of-aips.md).
