# 4.2.6.3 PDI is persistently associated with the Content Data Object

## Requirement Text

The repository shall ensure that the PDI is persistently associated with the relevant Content Data Object.

## Evidence Provided

APTrust ensures that PDI remains permanently associated with the Content Data Object by:

- Preserving original BagIt tag files as part of the AIP.
- Recording PREMIS events in preservation metadata attached to the intellectual object.
- Maintaining object and file relationships in the APTrust registry.
- Including complete PREMIS event histories in restored DIPs.

Because BagIt tag files and repository-generated preservation metadata are stored with and logically linked to the Content Data Object, PDI is not maintained separately from the objects it describes.

Also see [APtrust Bagging Requirements](https://aptrust.github.io/userguide/bagging/), [Ingest](https://aptrust.github.io/userguide/preservation/ingest/) and [Deletion](https://aptrust.github.io/userguide/preservation/deletion/)documentation.
